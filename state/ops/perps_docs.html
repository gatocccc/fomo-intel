/orders/limit

Request Body schema: application/json
asset
required
string
Enum: "BTC" "ETH" "SOL"

The asset or market to trade against for the limit order.

includeSerializedTx
boolean
Default: true

Sets whether to return a serialized transaction (serializedTxBase64) in the response.

inputToken
required
string
Enum: "BTC" "ETH" "SOL" "USDC"

The token symbol for the input token used to fund the limit order.

inputTokenAmount
required
string

The amount of tokens for the input token. NOTE: The token amount needs to be an integer and must conform to the token mint decimals specified onchain. For example, to deposit 1 SOL, the value would be '1000000000' (9 decimals).

leverage
string

Leverage of the limit order. Either provide leverage or sizeUsdDelta.

side
required
string
Enum: "long" "short"

Required when creating a limit order request.

sizeUsdDelta
string

The amount in USD for the size of the limit order (raw value with 6 decimal places). Either provide leverage or sizeUsdDelta.

triggerPrice
required
string

Trigger price at which the limit order will be executed (raw value with 6 decimal places). For example, to set a trigger price of $20, pass in 20000000.

walletAddress
string

The wallet address / public key for the trader. Required when creating a limit order that returns a serialized transaction.

/positions/decrease

Request Body schema: application/json
collateralUsdDelta
string or null

The amount of collateral to withdraw in USD from the position. Must be an integer representing the USD amount multiplied by 10^6 (1 million) to align with the 6 decimal places used for USDC/USDT tokens on-chain. For example, to decrease by $10 USD, set 'collateralUsdDelta' to 10000000; for $20.50 USD, set 'collateralUsdDelta' to 20500000.

entirePosition
boolean
Default: false

When set to true, this will close the position and transfer the remaining collateral and realised profits (if the position is profitable) to the trader.

maxSlippageBps
string
Default: "200"

The maximum slippage in (BPS) for the asset's price when executing the trade

positionPubkey
required
string

The public key for the open position. Use the GET positions endpoint to fetch the public key for the trader's open positions.

priorityFeeMicroLamports
string

Custom priority fee in microlamports for the transaction (1,000,000 microlamports = 1 lamport). If not set, the API will automatically set the optimal priority fee

receiveToken
required
string
Enum: "BTC" "ETH" "SOL" "USDC"

The token to receive.

sizeUsdDelta
string or null

The amount in USD to decrease the position size by. Must be an integer representing the USD amount multiplied by 10^6 (1 million) to align with the 6 decimal places used for USDC/USDT tokens on-chain. For example, to decrease by $10 USD, set 'sizeUsdDelta' to 10000000; for $20.50 USD, set 'sizeUsdDelta' to 20500000.

/positions/increase

Request Body schema: application/json
asset
required
string
Enum: "BTC" "ETH" "SOL"

The asset or market to trade against

inputToken
required
string
Enum: "BTC" "ETH" "SOL" "USDC"

The token symbol for the input token used to fund the position

inputTokenAmount
required
string

The amount of tokens for the input token to open the position or deposit collateral. NOTE: The token amount needs to be an integer and must conform to the token mint decimals specified onchain. For example, to deposit 1 SOL, the value would be '1000000000' (9 decimals)

leverage
string

Leverage of the increase position, up to 1 decimal place. Either provide 'leverage' or 'sizeUsdDelta' to open a trade. Min leverage is '1.1'. Max leverage for SOL is 250.0

maxSlippageBps
required
string

The maximum slippage in (BPS) for the asset's price when executing trade

priorityFeeMicroLamports
string

Custom priority fee in microlamports for the transaction (1,000,000 microlamports = 1 lamport). If not set, the API will automatically set the optimal priority fee

side
required
string
Enum: "long" "short"

Side for the trade

sizeUsdDelta
string

The amount in USD to increase the position size by. Must be an integer representing the USD amount multiplied by 10^6 (1 million) to align with the 6 decimal places used for USDC/USDT tokens on-chain. For example, to increase the position size by $10 USD, set 'sizeUsdDelta' to 10000000; for $0.50 USD, set 'sizeUsdDelta' to 500000. Either provide 'leverage' or 'sizeUsdDelta'.

Array of objects or null <= 2 items

TPSL requests to set. TPSL requests can only be set for positions that 150x leverage or below. Only 2 TPSLs can be set at a time.

walletAddress
string

The wallet address / public key for the trader, Required when opening a new position.
